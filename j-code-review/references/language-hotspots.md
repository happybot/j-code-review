# 语言热点

只在对应语言出现时加载。项目约定优先于本表。每条都要能指到具体代码位置；指不出位置就不报。

## 使用方式

1. 按扩展名、依赖清单、构建文件确认语言、版本和框架。
2. 只读相关小节，不要求全表通读。
3. 语言专项发现仍按 P0-P3 定级。纯风格偏好不阻塞提交。
4. 同一仓库有多种语言时，按边界分别检查。

## JavaScript / TypeScript

| 检查点 | 红旗 | 取证 |
| --- | --- | --- |
| 异步错误 | Promise 没有 await、return 或 catch；`forEach` 里用 `await`；异步回调未等待 | 指出未被处理的 Promise 和触发路径 |
| 空值与类型 | `any` 扩散、双重断言、非空断言、`@ts-ignore` 越过真实边界 | 指出断言位置和运行时数据来源 |
| 边界校验 | 只在类型层校验，HTTP、消息、存储、环境变量没有运行时 schema 校验 | 指出入口和缺失的校验 |
| 资源清理 | 监听器、定时器、订阅、WebSocket、observer 在异常和卸载路径未清理 | 指出注册点和缺失的清理 |
| 并发 | `Promise.all` 的部分成功语义、无界并发、乱序响应覆盖新状态 | 给出两个并发路径 |
| 安全 | 未转义输出到 `innerHTML`；SQL、命令、路径拼接；原型污染；SSRF | 从输入追到 sink |

## Python

| 检查点 | 红旗 | 取证 |
| --- | --- | --- |
| 可变默认参数 | 参数或状态跨调用共享；默认值被原地修改 | 指出参数和修改点 |
| 异常 | 裸 `except:`、过宽捕获、空 `except`、丢失异常上下文 | 指出 catch 和丢失原因的位置 |
| 资源 | 文件、锁、连接、生成器未用 context manager 或 `finally` | 指出所有返回路径 |
| 异步 | async 函数里有阻塞 IO、同步锁、未 await 的 coroutine | 指出阻塞调用和事件循环生命周期 |
| 安全 | `eval`/`exec`、不可信 `pickle`/YAML、shell 拼接、SQL 插值 | 说明输入来源和 sink |
| 类型边界 | 公共接口大量 `Any`、`cast` 滥用、运行时数据未校验 | 指出边界函数 |

## JVM（Java / Kotlin）

| 检查点 | 红旗 | 取证 |
| --- | --- | --- |
| 相等与哈希 | `equals`/`hashCode`/`compareTo` 不一致；可变对象作为 map/set key | 指出进入哈希容器的位置 |
| 空值 | 自动拆箱、nullable 边界、`Optional` 用错位置 | 指出可能为空的来源 |
| 资源 | 文件、stream、JDBC、锁、executor 在异常路径未释放 | 指出 try-with-resources 缺失点 |
| 并发 | 共享可变状态未安全发布；线程池无界；`CompletableFuture` 丢异常 | 指出共享状态和线程池配置 |
| 事务 | `@Transactional` 自调用失效、传播级别不符、外部副作用在事务内 | 指出代理调用路径和事务边界 |
| 安全 | SQL/JPQL 拼接、SSRF、路径穿越、反序列化类型过宽 | 从输入追到 sink |

## Go

| 检查点 | 红旗 | 取证 |
| --- | --- | --- |
| 错误 | error 被忽略、丢失上下文、比较方式错误 | 指出 error 产生和处理位置 |
| context | 未传播 context；把 context 存进长期对象；用 nil context | 指出调用链断点 |
| goroutine | 没有退出、取消或 backpressure；channel 未关闭 | 指出启动点和退出路径 |
| 竞态 | 共享 map/切片、懒初始化、闭包变量 | 指出共享写入点；有条件时跑 `-race` |
| 资源 | response body、文件、rows、ticker、listener 未释放 | 指出循环中的 defer 和异常路径 |
| HTTP | 客户端和服务端缺超时、大小上限、取消 | 指出请求入口和调用点 |

## Rust

| 检查点 | 红旗 | 取证 |
| --- | --- | --- |
| panic | 生产路径上的 `unwrap`/`expect`/索引 panic 可由外部输入触发 | 指出输入到 panic 的路径 |
| 错误 | `Result`/`Option` 丢失来源链、错误信息为空、调用方未处理 | 指出转换点 |
| 并发 | mutex 持有时间过长、锁顺序不一致、channel 关闭错误 | 指出锁范围和并发路径 |
| async | async 中阻塞 IO、runtime 混用、任务取消缺失 | 指出阻塞调用和 runtime 边界 |
| unsafe | unsafe 块没有不变量说明或范围过大 | 指出 unsafe 块和依赖的不变量 |
| 资源 | 为绕过借用产生大对象 clone、锁内 clone | 只在有规模或热点证据时报告 |

## C / C++

| 检查点 | 红旗 | 取证 |
| --- | --- | --- |
| 生命周期 | use-after-free、double free、悬空引用、越界、未初始化读取 | 指出所有权和释放点 |
| 资源管理 | 异常或早返回路径漏释放；C 项目 cleanup 路径不全 | 列出所有返回路径 |
| 未定义行为 | 有符号溢出、移位、对齐、strict aliasing、格式化不匹配 | 指出表达式和类型 |
| 输入边界 | 长度、索引、文件、网络输入直接进入内存或命令 sink | 从输入追到 sink |
| 并发 | 数据竞争、锁顺序、原子内存序、回调注销 | 指出共享状态和线程生命周期 |
| 头文件 | 缺 include guard、暴露实现细节、宏污染 | 指出头文件和包含关系 |

## C# / .NET

| 检查点 | 红旗 | 取证 |
| --- | --- | --- |
| 空值 | nullable 警告被 `!` 压制；外部输入没有运行时校验 | 指出压制点和输入来源 |
| async | 未 await 的 Task、`async void`（事件处理器除外）、同步阻塞 async | 指出调用链 |
| 资源 | `IDisposable`/`IAsyncDisposable` 未释放；HttpClient 生命周期错误 | 指出创建和释放点 |
| 并发 | 共享状态未同步；Channel/后台任务未关闭；重试不幂等 | 指出共享状态和关闭路径 |
| 安全 | 反射/反序列化、命令/路径/SQL 注入、日志 PII、授权边界 | 从输入追到 sink |
| EF Core | N+1、tracking 滥用、缺分页、事务和并发 token 错误 | 指出查询和事务边界 |

## SQL / API / 配置

| 检查点 | 红旗 | 取证 |
| --- | --- | --- |
| SQL | 拼接用户输入；循环内查询；缺分页；事务边界错误 | 指出查询和输入来源 |
| 迁移 | 锁表时间长、无回滚、无数据回填、双写窗口未处理 | 指出迁移步骤和回滚方案 |
| API 契约 | schema、枚举、错误码、分页、空值语义不兼容 | 指出新旧契约差异 |
| 配置 | 密钥硬编码、默认值掩盖缺失、环境差异未声明 | 指出配置键和使用点 |
